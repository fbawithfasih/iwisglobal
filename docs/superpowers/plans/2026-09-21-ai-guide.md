# AI Guide (YourGuide) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the hero search pill on iwisglobal's homepage with an AI-backed question box ("YourGuide") that answers real travel/tour questions using Claude Haiku, grounded in the site's live tour catalog, with hard rate limits so it can't run up an unbounded bill.

**Architecture:** A new D1 table (`ai_guide_requests`) backs a simple rate limiter. A new lib module (`src/lib/aiGuide.ts`) owns IP hashing, rate-limit checks, the system-prompt builder (which pulls live tour data via the existing `listTours()`), and the Anthropic API call. A new API route (`src/pages/api/ai-guide.ts`) wires those together behind `POST`. A new React island (`src/components/AiGuideBox.tsx`) replaces the hero's search pill and talks to that route.

**Tech Stack:** Astro 4 + Cloudflare adapter, React island (`client:load`), Cloudflare D1, Web Crypto (`crypto.subtle`), Anthropic Messages API (`claude-haiku-4-5-20251001`), plain `fetch` — no new npm dependencies.

**Spec:** `docs/superpowers/specs/2026-09-21-ai-guide-design.md`

## Global Constraints

- Rate limits: **10 requests/IP/24h**, **300 requests site-wide/24h**, **300 max output tokens** per answer (spec §"Rate limits").
- Model: `claude-haiku-4-5-20251001` (spec §Architecture).
- The system prompt must never let Claude state a price/ticket cost/timing not present in the live tour data injected into it (spec §"System prompt").
- `FALLBACK_TEXT` (rate-limited, missing config, or any API failure) is always: `"I couldn't get you an answer just now — you're welcome to browse our tours, or WhatsApp us at +91 6399226633 and we'll help directly."` — always returned as `200 { answer: FALLBACK_TEXT }`, never a 4xx/5xx (spec §"Request flow" step 4/6).
- No streaming, no server-persisted conversation history — only the last one Q&A exchange is kept client-side and resent (spec §Non-goals).
- This repo has **no test framework** (`CLAUDE.md`/`SESSION_HANDOFF.md`) — `npx astro check` is the only static check; every task's verification is `astro check` plus a manual `curl`/browser check, following this session's established pattern. Do not add a test framework as part of this plan (out of scope, not requested).
- This repo has **no CI** — every deploy is manual (`npm run deploy`, which runs `astro build && wrangler pages deploy`). Do not push/deploy until a task explicitly says to.
- Cloudflare Pages secrets bind on the **next** deploy after being set in the dashboard, not the currently-live one — relevant when `ANTHROPIC_API_KEY` is added.

- [ ] **Step 1: Write the file**

```ts
// src/lib/aiGuide.ts
//
// "YourGuide" — the AI-backed hero question box (src/components/AiGuideBox.tsx).
// Rate-limited via ai_guide_requests (see schema_ai_guide_usage.sql) so a
// burst of traffic or abuse can't run up an unbounded Anthropic bill.
// The system prompt is rebuilt from the live tour catalog on every
// request so Claude never has to invent a price — see buildSystemPrompt.

import type { D1Like } from './db';
import { toHex } from './passwordHash';

export const AI_GUIDE_MODEL = 'claude-haiku-4-5-20251001';
export const MAX_OUTPUT_TOKENS = 300;
export const RATE_LIMIT_PER_IP_PER_DAY = 10;
export const RATE_LIMIT_SITE_WIDE_PER_DAY = 300;

export const FALLBACK_TEXT =
  "I couldn't get you an answer just now — you're welcome to browse our tours, or WhatsApp us at +91 6399226633 and we'll help directly.";

const DAY_MS = 24 * 60 * 60 * 1000;

// Privacy-only hash of the visitor's IP so ai_guide_requests never stores
// a raw IP. Not a security boundary — anyone with the IP can recompute
// the same hash, since there's no secret salt involved.
export async function hashIp(ip: string): Promise<string> {
  const enc = new TextEncoder();
  const digest = await crypto.subtle.digest('SHA-256', enc.encode(ip));
  return toHex(digest);
}

export async function checkRateLimit(db: D1Like, ipHash: string): Promise<{ allowed: boolean }> {
  const since = Date.now() - DAY_MS;
  const [perIp, siteWide] = await Promise.all([
    db
      .prepare('SELECT COUNT(*) as count FROM ai_guide_requests WHERE ip_hash = ? AND created_at > ?')
      .bind(ipHash, since)
      .first<{ count: number }>(),
    db
      .prepare('SELECT COUNT(*) as count FROM ai_guide_requests WHERE created_at > ?')
      .bind(since)
      .first<{ count: number }>(),
  ]);
  const perIpCount = perIp?.count ?? 0;
  const siteWideCount = siteWide?.count ?? 0;
  return {
    allowed: perIpCount < RATE_LIMIT_PER_IP_PER_DAY && siteWideCount < RATE_LIMIT_SITE_WIDE_PER_DAY,
  };
}

// Called BEFORE the Anthropic call (not after) so a burst of concurrent
// requests can't all race past the cap while waiting on Claude. A request
// that then fails downstream still "spends" its slot for the day —
// accepted trade-off, simpler than a two-phase reserve/commit.
export async function recordRequest(db: D1Like, ipHash: string): Promise<void> {
  await db.prepare('INSERT INTO ai_guide_requests (ip_hash, created_at) VALUES (?, ?)').bind(ipHash, Date.now()).run();
}

export interface GuideTourSummary {
  title: string;
  amount: number;
  currency: string;
  durationLabel: string;
}

export function buildSystemPrompt(tours: GuideTourSummary[]): string {
  const catalogLines = tours.length
    ? tours.map((t) => `- ${t.title} — ${t.amount} ${t.currency} per traveler, ${t.durationLabel}`).join('\n')
    : '- (no published tours currently available — direct the visitor to /tours or WhatsApp)';

  return `You are YourGuide, a friendly travel assistant for IWIS Global, a private Taj Mahal & Agra tour operator based in Agra, India.

Answer questions about visiting Agra and the Taj Mahal, and about IWIS Global's tours, using ONLY:
1. The CURRENT TOURS data below (this is live, accurate data).
2. Safe, general, widely-known travel knowledge (dress modestly at religious/heritage sites, mornings are best for photos and cooler weather, etc.).

Never state a specific ticket price, monument entry fee, or timing that is not in the CURRENT TOURS data below. If asked for a figure you don't have verified data for, say so plainly and point to /tours, /guides, or WhatsApp (+91 6399226633) instead of guessing.

Keep answers to 2-4 sentences. If asked something unrelated to travel, Agra, or IWIS Global's tours, politely decline and redirect to travel questions.

CURRENT TOURS:
${catalogLines}`;
}

export interface GuideExchange {
  q: string;
  a: string;
}

export async function askYourGuide(
  message: string,
  history: GuideExchange[],
  systemPrompt: string,
  apiKey: string
): Promise<string> {
  const messages: { role: 'user' | 'assistant'; content: string }[] = [];
  // Only the single most recent exchange is ever passed in (enforced by
  // the API route, Task 3) — this loop just flattens it into the shape
  // the Messages API expects.
  for (const exchange of history) {
    messages.push({ role: 'user', content: exchange.q });
    messages.push({ role: 'assistant', content: exchange.a });
  }
  messages.push({ role: 'user', content: message });

  const res = await fetch('https://api.anthropic.com/v1/messages', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'x-api-key': apiKey,
      'anthropic-version': '2023-06-01',
    },
    body: JSON.stringify({
      model: AI_GUIDE_MODEL,
      max_tokens: MAX_OUTPUT_TOKENS,
      system: systemPrompt,
      messages,
    }),
  });

  if (!res.ok) {
    throw new Error(`Anthropic API error: ${res.status}`);
  }

  const json: any = await res.json();
  const text = json?.content?.[0]?.text;
  if (typeof text !== 'string' || !text.trim()) {
    throw new Error('Anthropic API returned no text');
  }
  return text.trim();
}
```

**Interfaces:**

- [ ] **Step 1: Write the route**

```ts
// src/pages/api/ai-guide.ts
import type { APIRoute } from 'astro';
import { resolveEnv } from '../../lib/env';
import { listTours } from '../../lib/tours';
import {
  hashIp,
  checkRateLimit,
  recordRequest,
  buildSystemPrompt,
  askYourGuide,
  FALLBACK_TEXT,
  type GuideExchange,
} from '../../lib/aiGuide';

export const prerender = false;

const MAX_MESSAGE_LENGTH = 300;

function fallbackResponse() {
  return new Response(JSON.stringify({ answer: FALLBACK_TEXT }), {
    status: 200,
    headers: { 'Content-Type': 'application/json' },
  });
}

export const POST: APIRoute = async ({ request, locals }) => {
  let message = '';
  let history: GuideExchange[] = [];

  try {
    const body = await request.json();
    message = typeof body?.message === 'string' ? body.message.trim().slice(0, MAX_MESSAGE_LENGTH) : '';
    history = Array.isArray(body?.history)
      ? body.history
          .filter((h: any) => typeof h?.q === 'string' && typeof h?.a === 'string')
          .slice(-1)
      : [];
  } catch {
    return new Response(JSON.stringify({ error: 'Invalid request body' }), {
      status: 400,
      headers: { 'Content-Type': 'application/json' },
    });
  }

  if (!message) {
    return new Response(JSON.stringify({ error: 'Missing message' }), {
      status: 400,
      headers: { 'Content-Type': 'application/json' },
    });
  }

  const env = resolveEnv(locals);
  const db = env.DB;
  const apiKey = env.ANTHROPIC_API_KEY;

  // Missing config (D1 not bound locally, or ANTHROPIC_API_KEY not yet
  // set/propagated) degrades to the same fallback a rate-limited visitor
  // sees — never a 500, per the spec's "never a raw error" rule.
  if (!db || !apiKey) {
    return fallbackResponse();
  }

  try {
    const ip = request.headers.get('cf-connecting-ip') ?? 'unknown';
    const ipHash = await hashIp(ip);
    const { allowed } = await checkRateLimit(db, ipHash);
    if (!allowed) {
      return fallbackResponse();
    }

    await recordRequest(db, ipHash);

    const tours = await listTours(db, { status: 'published' });
    const systemPrompt = buildSystemPrompt(
      tours.map((t) => ({ title: t.title, amount: t.amount, currency: t.currency, durationLabel: t.durationLabel }))
    );

    const answer = await askYourGuide(message, history, systemPrompt, apiKey);
    return new Response(JSON.stringify({ answer }), {
      status: 200,
      headers: { 'Content-Type': 'application/json' },
    });
  } catch {
    return fallbackResponse();
  }
};
```

```tsx
// src/components/AiGuideBox.tsx
//
// Replaces the hero's old "Search tours in Agra" pill (src/pages/index.astro)
// with an AI-backed question box, per docs/superpowers/specs/2026-09-21-ai-guide-design.md.
import { useState, type FormEvent } from 'react';

const MAX_LENGTH = 300;
const CLIENT_FALLBACK = "I couldn't get you an answer just now — please browse our tours or WhatsApp us.";

interface Exchange {
  q: string;
  a: string;
}

declare global {
  interface Window {
    dataLayer?: unknown[];
  }
}

export default function AiGuideBox() {
  const [message, setMessage] = useState('');
  const [history, setHistory] = useState<Exchange[]>([]);
  const [answer, setAnswer] = useState<string | null>(null);
  const [loading, setLoading] = useState(false);

  async function submit(e: FormEvent) {
    e.preventDefault();
    const trimmed = message.trim().slice(0, MAX_LENGTH);
    if (!trimmed || loading) return;

    setLoading(true);
    setAnswer(null);

    window.dataLayer = window.dataLayer || [];
    window.dataLayer.push({ event: 'ai_guide_asked' });

    try {
      const res = await fetch('/api/ai-guide', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ message: trimmed, history }),
      });
      const json = await res.json();
      const text = typeof json?.answer === 'string' ? json.answer : CLIENT_FALLBACK;
      setAnswer(text);
      setHistory([{ q: trimmed, a: text }]);
      setMessage('');
    } catch {
      setAnswer(CLIENT_FALLBACK);
    } finally {
      setLoading(false);
    }
  }

  return (
    <div className="w-full max-w-md mx-auto">
      <form
        onSubmit={submit}
        className="flex items-center justify-between gap-4 w-full bg-white rounded-full pl-6 pr-2 py-2 shadow-lg hover:shadow-xl transition"
      >
        <input
          type="text"
          value={message}
          onChange={(e) => setMessage(e.target.value)}
          maxLength={MAX_LENGTH}
          placeholder="YourGuide — ask me anything about your travel"
          aria-label="Ask YourGuide a travel question"
          className="flex-1 bg-transparent text-stone-700 text-sm placeholder:text-stone-500 outline-none"
        />
        <button
          type="submit"
          disabled={loading}
          aria-label="Ask YourGuide"
          className="flex items-center justify-center h-11 w-11 rounded-full bg-brand-800 text-white shrink-0 disabled:opacity-60 transition"
        >
          {loading ? (
            <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2" className="h-5 w-5 animate-spin">
              <path strokeLinecap="round" d="M12 3a9 9 0 1 0 9 9" />
            </svg>
          ) : (
            <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2" className="h-5 w-5">
              <path strokeLinecap="round" strokeLinejoin="round" d="M12 3l1.8 4.5L18 9l-4.2 1.5L12 15l-1.8-4.5L6 9l4.2-1.5L12 3z" />
            </svg>
          )}
        </button>
      </form>

      <a href="/tours" className="block text-center text-sm text-white/80 hover:text-white transition mt-3">
        Browse tours →
      </a>

      {answer && (
        // Higher opacity (90% vs the weather card's 40%) than the
        // lavender-section glass card — this one sits over a busy photo,
        // not a flat color, so it needs more contrast to stay legible.
        <div className="mt-4 rounded-xl border border-white/50 bg-white/90 backdrop-blur-md p-4 text-left text-sm text-stone-700 leading-relaxed">
          {answer}
        </div>
      )}
    </div>
  );
}
```
